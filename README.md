# Bangla Creator Toolkit

A free, lightweight toolkit for Bengali and English content creators. It helps users count text, clean spacing, format captions, and prepare hashtags from their own keywords.

## Features

- Character, word, and line counter
- Remove repeated spaces and excessive blank lines
- Break long captions into readable paragraphs
- Build a hashtag line from user-provided keywords
- Copy text to the clipboard
- Responsive layout for phones and desktop
- No account, backend, or server-side text storage required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start using the tools.

No build step or package installation is needed.

## Privacy

All text processing happens in the user's browser. This project does not send entered text to a server.
